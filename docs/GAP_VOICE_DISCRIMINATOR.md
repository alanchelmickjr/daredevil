# Gap analysis — real-time voice discriminator (M2 MacBook)

**Date:** 2026-07-01 (live session on Alan's M2, `daredevil serve --live --port 8770`, conda env `daredevil`, all reference backends).
**Method:** every gap below was independently found by reader agents, then adversarially re-verified against the working tree, the on-disk state (`~/.daredevil/`), and the live run logs (`/tmp/daredevil.log`, `scratchpad/serve2.log`). Corrected citations from the verification pass are used throughout. Nothing here is asserted without a file:line or artifact. Uncommitted working-tree changes as of this analysis (manager.py 3A LLR cap + immediate-accept hysteresis + decided-first tie-break; cli.py synthetic-enroll warning; calibrate.py read-aloud script; tests) were checked against every gap — **none of them fix a blocker, and the hysteresis extension strengthens blocker B2.**

## Definition of done (acceptance criteria for "working", testable)

1. **Continuous listening:** with zero HTTP clients attached, the log shows ≥55 analyzed 1.0s windows per 60s wall clock, sustained 10 min. Closing the browser must not stop capture.
2. **Owner acquisition:** enrolled owner speaking ≥3s at conversational level is named on the HUD within ≤4s wall clock, ≥9/10 trials.
3. **Revocable hold:** identity persists across ≤10s pauses; when a *different* voice takes over the same track, the owner label demotes within ≤10s. No permanent misattribution path may exist.
4. **Impostor rejection:** 10 min of TV/guest speech with owner silent → zero `MATCHED <owner>` log lines; those sources surface as `UNKNOWN-NNN`.
5. **Honest calibration:** target stats fit on held-out audio; impostor stats fit on (or floored to) *voice* cosines, with the H0 source labeled in `calibration.json`; the fitted model governs the *running* matcher without a process restart.
6. **Restart survival:** process restart with same `DAREDEVIL_KEY` → owner recognized without re-enrollment; missing/changed key → explicit "N records unreadable" surfaced, not silent empty store.
7. **Truthful HUD:** no bearing rendered when `map.array.spatial=false`; audio-age/lag surfaced; `active_speaker` non-null while the owner speaks on the PANNs backend; a stale map is never presented as live.
8. **Store hygiene:** bare `daredevil serve` (synthetic demo) writes nothing to the reference voiceprint store; silence/garbage cannot be enrolled.
